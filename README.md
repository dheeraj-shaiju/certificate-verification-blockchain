# Certificate Verification System Using Blockchain

A decentralized academic credential verification platform built on Ethereum smart contracts and IPFS.
Colleges issue tamper-proof degree certificates, students share them with a QR code, and employers can verify them in seconds.

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

Then open http://localhost:5173. Demo logins are listed on the login page and in `frontend/README.md`.
